# Work Time Tracker - 管理者権限設定ガイド

## 管理者権限の設定方法

### 1. 環境変数の設定

プロジェクトルートに `.env.local` ファイルを作成し、以下のように管理者のメールアドレスを設定してください：

```bash
# 管理者権限を付与するメールアドレス（複数の場合はカンマ区切り）
REACT_APP_ADMIN_EMAILS=admin@example.com,manager@example.com,your-email@example.com
```

### 2. 設定例

```bash
# 単一の管理者
REACT_APP_ADMIN_EMAILS=admin@example.com

# 複数の管理者
REACT_APP_ADMIN_EMAILS=admin@example.com,manager@example.com,owner@example.com
```

### 3. 確認方法

1. **ブラウザの開発者ツール（Console）で確認**
   - ログイン後、コンソールで以下のようなログが表示されます：
   ```
   [AuthContext] 管理者メールアドレス設定: ["admin@example.com"]
   [AuthContext] ユーザーメールアドレス: admin@example.com
   [AuthContext] 管理者権限が付与されました: admin@example.com
   ```

2. **UIでの確認**
   - ログイン成功時に「管理者権限でログインしました」通知が表示
   - サイドバーのプロフィール部分に👑アイコンが表示
   - ユーザーメニューに「管理者」バッジが表示

## 管理者機能

### ブログ投稿の管理

#### 1. **全ての投稿に対する操作権限**
- 他のユーザーが作成した投稿も編集・削除可能
- 管理者権限での操作は明確に表示される

#### 2. **ブログ一覧ページ**
- **管理者モード表示**: ページ上部に管理者権限の案内が表示
- **統計情報**: 自分の投稿数と他ユーザーの投稿数を表示
- **視覚的な区別**: 他ユーザーの投稿は黄色のボーダーで表示
- **操作メニュー**: 全ての投稿に編集・削除ボタンが表示

#### 3. **ブログ詳細ページ**
- **管理者モード警告**: 他ユーザーの投稿を表示中は警告バーが表示
- **明確な表示**: 「管理者操作」「他ユーザー投稿」のチップが表示
- **削除確認**: 管理者権限での削除は特別な確認ダイアログが表示

#### 4. **削除時の特別表示**
```
✅ 自分の投稿削除: "ブログ記事を削除しました"
🔧 管理者権限削除: "管理者権限でブログ記事を削除しました"
```

## セキュリティ

### 権限チェックのロジック

```typescript
const canModifyPost = (postAuthor: string) => {
  if (!user) return false;
  
  // 管理者は全ての投稿を編集・削除可能
  if (user.isAdmin) return true;
  
  // 作成者は自分の投稿のみ編集・削除可能
  return postAuthor === user.email || postAuthor === user.name;
};
```

### 注意点

1. **環境変数の管理**
   - `.env.local` は git にコミットしないでください
   - 本番環境では適切に環境変数を設定してください

2. **権限の確認**
   - 管理者権限はログイン時に設定されます
   - プロフィール更新時も権限が再確認されます

3. **トラブルシューティング**
   - 管理者権限が付与されない場合は、コンソールログを確認
   - メールアドレスの大文字小文字、スペースに注意
   - ブラウザをリロードして再ログインを試行

## 開発用のテスト

### 管理者権限のテスト手順

1. テスト用管理者アカウントでユーザー登録
2. `.env.local` にそのメールアドレスを追加
3. アプリケーションを再起動（`npm start`）
4. 管理者アカウントでログイン
5. 他のユーザーの投稿で編集・削除ボタンが表示されることを確認

### デバッグ情報

開発時は以下のコンソールログで権限設定を確認できます：

```javascript
// ユーザー情報の確認
console.log('Current user:', user);
console.log('Is admin:', user?.isAdmin);

// 環境変数の確認  
console.log('Admin emails:', process.env.REACT_APP_ADMIN_EMAILS);
```

## よくある質問

**Q: 管理者権限が効かない**
A: 以下を確認してください：
- `.env.local` ファイルが正しい場所にあるか
- メールアドレスの記述に誤りがないか
- アプリケーションを再起動したか

**Q: 複数の管理者を設定したい**
A: カンマ区切りで複数のメールアドレスを設定してください：
```bash
REACT_APP_ADMIN_EMAILS=admin1@example.com,admin2@example.com
```

**Q: 本番環境での設定方法**
A: デプロイ先の環境変数設定で `REACT_APP_ADMIN_EMAILS` を設定してください。
