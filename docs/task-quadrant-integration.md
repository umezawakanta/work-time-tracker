# タスク管理センターと4象限マトリックスの統合

## 概要

タスク管理センターと4象限マトリックス（アイゼンハワーマトリックス）を統合し、一つの統合タスク管理ページで両方の機能を利用できるようにしました。

## 🎯 統合内容

### 統合前の状況

- **タスク管理センター** (`/tasks`) - 独立したページ
- **4象限マトリックス** (`/quadrant-dashboard`) - 別の独立したページ

### 統合後の状況

- すべての機能が **タスク管理センター** (`/tasks`) に統合
- 4象限マトリックスは新しいタブとして追加
- 旧URL (`/quadrant-dashboard`) は自動的に新しい場所にリダイレクト

## 📍 アクセス方法

### 方法1: タスク管理センター内のタブから

1. `/tasks` にアクセス
2. 「4象限」タブをクリック

### 方法2: 直接URLアクセス

- `/tasks?tab=quadrant` - 4象限マトリックスタブを直接開く
- `/quadrant-dashboard` - 自動的に `/tasks?tab=quadrant` にリダイレクト

### 方法3: サイドメニューから

- 左側のメニューの「🎯 4象限マトリックス」をクリック
- タスク管理センターの4象限タブが開きます
