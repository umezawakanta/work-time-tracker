# タスクカレンダー週表示の修正

## 2025年1月16日 実装

### 問題

タスクカレンダーの週表示にタスクが表示されていなかった。

### 原因

以前の実装では、以下の条件でのみタスクが表示されていた：

1. 期限のあるタスク → 期限日に表示
2. **今日作成されたタスクのみ** → 今日に表示

このため、週表示で今日以外の日付のタスクが表示されていなかった。

### 修正内容

#### 1. タスク表示ロジックの改善

**修正前：**

```javascript
// 今日作成されたタスクのみ表示
if (todo.createdAt && new Date(todo.createdAt).toDateString() === new Date().toDateString()) {
  // 今日のイベントとして追加
}
```

**修正後：**

```javascript
// すべての未完了タスクを適切な日付に表示
if (!todo.completed) {
  let taskDate: Date;

  if (todo.deadline) {
    // 期限がある場合はスキップ（既に追加済み）
    return;
  } else if (todo.createdAt) {
    // 作成日がある場合は作成日に表示
    taskDate = new Date(todo.createdAt);
  } else {
    // それ以外は今日に表示
    taskDate = new Date();
  }

  events.push({
    id: `task-${todo._id}`,
    title: `🔘 ${todo.task}`,
    start: taskDate,
    end: taskDate,
    resource: todo,
    type: 'task',
  });
}
```

#### 2. 完了済みタスクの表示

完了済みタスクも完了日に表示するように追加：

```javascript
if (todo.completed && todo.completedAt) {
  const completedDate = new Date(todo.completedAt);
  events.push({
    id: `completed-${todo._id}`,
    title: `✅ ${todo.task}`,
    start: completedDate,
    end: completedDate,
    resource: todo,
    type: 'task',
  });
}
```

### タスク表示ルール

現在の実装では、以下のルールでタスクが表示されます：

| タスクの状態         | 表示日 | アイコン | 説明                   |
| -------------------- | ------ | -------- | ---------------------- |
| 期限あり             | 期限日 | 📅       | 期限のあるタスク       |
| 未完了（期限なし）   | 作成日 | 🔘       | 進行中のタスク         |
| 未完了（作成日なし） | 今日   | 🔘       | デフォルトで今日に表示 |
| 完了済み             | 完了日 | ✅       | 完了したタスク         |

### ビュー別の表示

#### 月表示

- すべてのタスクが該当する日付に表示
- 1日に複数のタスクがある場合はリスト表示

#### 週表示

- 1週間分のタスクが日ごとに表示
- 時間軸で表示される

#### 日表示

- 選択した日のタスクのみ表示
- 詳細な時間割で表示

### メリット

1. **週表示の改善**
   - すべてのタスクが適切な日付に表示される
   - 週全体のタスク状況が把握できる

2. **視認性の向上**
   - アイコンで状態が一目で分かる
   - 未完了/完了が明確に区別される

3. **スケジュール管理**
   - 作成日ベースでタスクの履歴が追跡可能
   - 完了タスクも履歴として確認可能

### 使用方法

1. **ビューの切り替え**
   - 「月」「週」「日」ボタンで切り替え
   - デフォルトは月表示

2. **タスクのドラッグ&ドロップ**
   - タスクをドラッグして日付変更可能
   - 期限の変更に反映される

3. **タスクの詳細表示**
   - タスクをクリックで詳細モーダル表示
   - 編集や完了マークが可能

### 今後の改善案

1. **フィルタリング機能**
   - 完了/未完了の表示切り替え
   - カテゴリー別フィルター
   - 優先度別表示

2. **時間管理**
   - タスクの推定時間表示
   - 時間帯での配置
   - タイムブロッキング

3. **繰り返しタスク**
   - 定期的なタスクの自動生成
   - リマインダー機能
