# タスク分析キャッシュ最適化

## 2025年1月16日 実装

### 概要

一度分析が完了したタスクを再分析しないようにする最適化を実装しました。これにより、Gemini APIのレート制限対策とパフォーマンス向上を実現しています。

### 実装内容

#### 1. 永続化キャッシュ

- **LocalStorage活用**: 分析結果をブラウザのLocalStorageに保存
- **自動復元**: アプリ起動時に前回の分析結果を自動復元
- **最大100件保持**: 古いキャッシュは自動的に削除

```javascript
// キャッシュの永続化
const CACHE_STORAGE_KEY = 'quadrant_classification_cache';

// 永続化されたキャッシュをロード
const loadPersistedCache = () => {
  const cached = localStorage.getItem(CACHE_STORAGE_KEY);
  if (cached) {
    const parsedCache = JSON.parse(cached);
    // キャッシュから復元
  }
};
```

#### 2. インテリジェントなキャッシュキー

タスクの内容に基づいてキャッシュキーを生成：

```javascript
// タスクの主要な内容でハッシュキーを生成
const contentHash = `${task.title}|${task.description}|${task.priority}|${task.deadline}|${task.isCompleted}`;
const cacheKey = `${task.id}_${contentHash}`;
```

**メリット**:

- タスクの内容が変更された時のみ再分析
- 不要な再分析を防止
- APIコール数を最小化

#### 3. キャッシュヒット率の可視化

分析時にキャッシュの利用状況を表示：

```
📌 キャッシュヒット率: 80% (12/15件)
🚀 新規分析が必要なタスク: 3件
✅ 分析完了: 合計15件（キャッシュ: 12件, 新規API: 3件）
```

#### 4. キャッシュクリア機能

UIにキャッシュクリアボタンを追加：

- ゴミ箱アイコンボタンでキャッシュを手動クリア
- 必要に応じて強制的に再分析可能

### パフォーマンス改善

#### Before（最適化前）

- 毎回すべてのタスクをAPI分析
- 15タスクで約20秒かかる
- 頻繁にレート制限エラー（429）

#### After（最適化後）

- 初回のみAPI分析
- 2回目以降はキャッシュから即座に取得（< 1秒）
- レート制限エラーが大幅に減少

### 使用方法

#### 通常の分析

1. タスク管理センターの「4象限」タブを開く
2. 自動的にキャッシュをチェック
3. 新規タスクのみAPI分析
4. 結果は自動的に保存

#### キャッシュクリア

1. ゴミ箱アイコンをクリック
2. 確認メッセージが表示
3. 次回分析時に全タスクを再分析

#### キャッシュの有効期限

- **タスク内容が変更されるまで有効**
- タイトル、説明、優先度、期限、完了状態のいずれかが変更されると自動的に再分析

### 技術詳細

#### キャッシュ戦略

1. **L1キャッシュ**: メモリ内Map（高速アクセス）
2. **L2キャッシュ**: LocalStorage（永続化）
3. **自動同期**: メモリとストレージを自動同期

#### API最適化

```javascript
// キャッシュ済みと新規タスクを分離
for (const task of tasks) {
  if (キャッシュに存在) {
    // キャッシュから取得（APIコールなし）
    cachedCount++;
  } else {
    // API分析が必要
    tasksNeedingApiCall.push(task);
  }
}
```

### 今後の改善案

1. **キャッシュ有効期限**
   - 時間ベースの有効期限設定
   - 古いキャッシュの自動更新

2. **バックグラウンド更新**
   - アイドル時に古いキャッシュを更新
   - プログレッシブな再分析

3. **キャッシュ統計**
   - ヒット率の履歴表示
   - API使用量の可視化

4. **共有キャッシュ**
   - チーム間でのキャッシュ共有
   - サーバーサイドキャッシュ

### トラブルシューティング

#### キャッシュが効かない場合

1. ブラウザの開発者ツールでLocalStorageを確認
2. `quadrant_classification_cache`キーの存在を確認
3. キャッシュクリアボタンで手動リセット

#### 分析結果が古い場合

1. キャッシュクリアボタンをクリック
2. ページをリロード
3. 再分析を実行
