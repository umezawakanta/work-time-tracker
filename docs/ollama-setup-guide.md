# Ollama ローカルLLM セットアップガイド

## 概要

Ollamaは、ローカル環境で大規模言語モデル（LLM）を実行できるツールです。Work Time Trackerの4象限マトリックス機能で、プライバシー重視・完全無料でAI分析を実行できます。

## 特徴

### メリット

- ✅ **完全無料**: APIキー不要、使用制限なし
- ✅ **プライバシー保護**: データが外部に送信されない
- ✅ **高速処理**: ネットワーク遅延なし
- ✅ **オフライン対応**: インターネット接続不要
- ✅ **カスタマイズ可能**: 好きなモデルを選択可能

### デメリット

- ⚠️ **初期設定が必要**: Ollamaのインストールが必要
- ⚠️ **ハードウェア要件**: GPUまたは十分なRAMが必要
- ⚠️ **精度**: クラウドAIより劣る場合がある

## システム要件

### 最小要件

- **RAM**: 8GB以上
- **ストレージ**: 10GB以上の空き容量
- **OS**: Windows 10+, macOS 11+, Linux

### 推奨要件

- **RAM**: 16GB以上
- **GPU**: NVIDIA GPU（VRAM 6GB以上）
- **ストレージ**: 20GB以上の空き容量

## インストール手順

### 1. Ollamaのインストール

#### Windows

1. [Ollama公式サイト](https://ollama.com/download)にアクセス
2. 「Download for Windows」をクリック
3. インストーラーを実行
4. デフォルト設定でインストール

#### macOS

```bash
# Homebrewを使用
brew install ollama

# または公式インストーラーを使用
curl -fsSL https://ollama.com/install.sh | sh
```

#### Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. Ollamaサービスの起動

#### Windows（自動起動）

インストール後、自動的にバックグラウンドで起動します。

#### macOS/Linux

```bash
# サービスを起動
ollama serve
```

### 3. モデルのダウンロード

ターミナル/コマンドプロンプトで以下を実行：

```bash
# 推奨モデル（日本語対応、軽量）
ollama pull llama3.2:3b

# その他のオプション
ollama pull mistral:7b     # より高精度
ollama pull phi3:mini      # 超軽量
ollama pull qwen2.5:7b     # 日本語特化
```

### 4. 動作確認

```bash
# モデル一覧を確認
ollama list

# テスト実行
ollama run llama3.2:3b "Hello, world!"
```

## Work Time Trackerでの設定

### 1. 環境変数（オプション）

デフォルトモデルを変更したい場合は`.env`ファイルに追加：

```env
# Ollamaモデル設定（オプション）
VITE_OLLAMA_MODEL=llama3.2:3b
```

### 2. アプリケーションでの使用

1. タスク管理センター → 4象限タブを開く
2. 右上のAIプロバイダー選択ドロップダウンをクリック
3. 「🦙 ローカルLLM (Ollama)」を選択
4. 「再分析」ボタンをクリック

## トラブルシューティング

### Ollamaが「未接続」と表示される

1. **Ollamaサービスの確認**

   ```bash
   # サービスが起動しているか確認
   curl http://localhost:11434/api/tags
   ```

2. **ポートの確認**
   - デフォルトポート: 11434
   - ファイアウォールでブロックされていないか確認

3. **サービスの再起動**

   ```bash
   # Windows
   # タスクマネージャーでOllamaを終了し、再起動

   # macOS/Linux
   killall ollama
   ollama serve
   ```

### 分析が遅い

1. **より小さいモデルを使用**

   ```bash
   ollama pull phi3:mini
   ```

2. **GPUアクセラレーションを有効化**（NVIDIA GPU搭載の場合）
   - CUDAがインストールされているか確認
   - Ollamaが自動的にGPUを検出

### メモリ不足エラー

1. **モデルサイズを確認**

   ```bash
   ollama list
   ```

2. **不要なモデルを削除**

   ```bash
   ollama rm model_name
   ```

3. **システムメモリを増やす**
   - 他のアプリケーションを終了
   - スワップファイルを増やす

## パフォーマンス最適化

### 1. モデル選択の最適化

```env
# 高速処理優先
VITE_OLLAMA_MODEL=phi3:mini

# バランス型
VITE_OLLAMA_MODEL=llama3.2:3b

# 精度優先
VITE_OLLAMA_MODEL=mistral:7b
```

### 2. コンテキスト設定

より少ないコンテキストで高速化：

- `num_ctx: 2048`（デフォルト: 4096）

### 3. バッチ処理

大量のタスクがある場合：

- 最大50タスクまで一度に処理可能
- メモリに応じて調整

## セキュリティ

- **データ漏洩リスクなし**: すべての処理がローカル

## よくある質問

### Q: どのモデルを選べばいいですか？

A: 初めての方は`llama3.2:3b`がおすすめです。バランスが良く、日本語対応も良好です。

### Q: GPUは必須ですか？

A: 必須ではありません。CPUのみでも動作しますが、GPUがあると5-10倍高速になります。

### Q: 複数のモデルを切り替えられますか？

A: はい、`.env`ファイルの`VITE_OLLAMA_MODEL`を変更するか、`ollama pull`で複数モデルをダウンロードして切り替えられます。

### Q: クラウドAIとの精度差はどの程度ですか？

A: タスク分類のような単純なタスクでは、ほとんど差はありません。複雑な推論が必要な場合は、クラウドAIの方が優れている場合があります。
