# 🚭 禁煙コーチ（Quit Smoking Coach）

禁煙継続を実戦的に支援する機能です。AIコーチ、衝動対処タイマー、節約額・健康効果の可視化、トリガー記録を備えています。

## アクセス方法

- 左サイドバー → 個人・ライフスタイル → 「🚭 禁煙コーチ」
- 直接URL: `/quit-smoking`

## できること

- 即時対処: 3分/5分タイマーで「今」の衝動の波を乗り切る
- 衝動記録: 強度(1-10)、トリガー、メモ、耐えた/吸ったをワンタップ記録
- AIコーチ: 状況と履歴を踏まえた短く具体的な提案（Anthropic Claude／サーバ未設定時はオフライン提案に自動フォールバック）
- 可視化: 禁煙継続時間、避けた本数、節約額を自動計算
- スリップ対応: 吸ってしまった記録でも「すぐ再開」設計（再開の敷居ゼロ）

## 使い方（最短30秒）

1. 禁煙開始日・価格・本数などを設定
2. 吸いたくなったら「今すぐ吸いたい」セクションでトリガー/強度を選ぶ
3. 3分タイマーを開始 → 深呼吸や水分補給など即効ガイドを実施
4. 結果を「耐えた」or「吸ってしまった」で記録
5. 不安や状況をAIコーチに相談（提案ボタンも便利）

## ベストプラクティス

- 朝一に「禁煙の理由」を読み上げる（設定で複数登録）
- よくあるトリガーを事前に登録しておく
- スリップしても数分以内に再開（再開に手続き不要）
- 週1回マイルストーン達成を確認して自分を称賛する

## プライバシー

- 記録はブラウザのローカルストレージに保存（サーバ送信なし）。
- データ初期化は画面右上「初期化」。

## 技術メモ（開発向け）

- ルート: `/quit-smoking`
- ページ: `src/pages/QuitSmokingCoachPage.tsx`
- 状態管理: `src/hooks/useQuitSmoking.ts`（LocalStorage永続化）
- AI連携: `anthropicService.chat()` を使用。失敗時はオフライン提案にフォールバック。
