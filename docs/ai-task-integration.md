# AI タスク管理統合ガイド

## 概要

Work Time TrackerにおけるClaude AI（Anthropic）とタスク管理機能の統合について説明します。

## 🎯 主要機能

### 1. 自然言語によるタスク操作

AIチャットまたはタスク管理ページから、自然な言葉でタスクを操作できます。

#### 使用例：

- 「会議の準備というタスクを作成して」
- 「優先度の高いタスクを教えて」
- 「メール返信を完了にして」
- 「今週のタスクを分析して」

### 2. AI タスク分析

タスクの優先度、時間見積もり、依存関係を自動的に分析します。

#### 分析内容：

- **優先度最適化**: タスクの重要度と緊急度を評価
- **時間予測**: 各タスクの所要時間を見積もり
- **グループ化提案**: 関連タスクをグループ化
- **タスク分解**: 複雑なタスクをサブタスクに分解

### 3. スマートタスク提案

AIがタスクの内容を理解し、次のアクションを提案します。

## 📱 利用方法

### タスク管理ページから

1. タスク管理ページ（`/todos`）にアクセス
2. 「AI分析」ボタンをクリック
3. AITaskSuggestionsコンポーネントが表示される
4. 各タブで分析結果を確認

### AIアシスタントページから

1. AIアシスタントページ（`/ai-assistant`）にアクセス
2. 「タスク管理」タブを選択
3. 自然言語でタスクを操作

### AIチャットから

1. AIチャットを開く
2. タスクに関する質問や指示を入力
3. AIが自動的にタスク操作を実行

## 🛠️ 技術仕様

### コンポーネント構成

```
src/components/ai/
├── AITaskManager.tsx      # タスク管理専用AIコンポーネント
├── AITaskSuggestions.tsx  # タスク分析・提案コンポーネント
├── AIChat.tsx             # 汎用AIチャットコンポーネント

```

## 🔧 設定項目

### 環境変数

```env
ANTHROPIC_API_KEY=sk-ant-api03-xxxxx
VITE_ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
VITE_ANTHROPIC_MAX_TOKENS=8192
VITE_AI_RATE_LIMIT=10
VITE_AI_RATE_WINDOW_MS=60000
```

### AIモデル設定

- **モデル**: Claude 3.5 Sonnet
- **最大トークン数**: 8192
- **温度**: 0.7（創造性と正確性のバランス）
- **レート制限**: 1分間に10リクエスト

1. http://localhost:3000/todos にアクセス

## 🔍 トラブルシューティング

### AIが応答しない

1. APIキーが正しく設定されているか確認
2. レート制限に達していないか確認
3. ネットワーク接続を確認

### タスク操作が失敗する

1. タスクIDが正しいか確認
2. 権限設定を確認
3. Redux状態を確認

### 分析結果が不正確

1. タスクの記述を具体的にする
2. 優先度設定を見直す
3. AIモデルの設定を調整
