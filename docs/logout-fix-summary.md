# ログアウト機能の修正

## 問題

- ログアウト時に `DELETE /api/user/session` への404エラーが発生
- バックエンドに該当エンドポイントが存在しなかった

## 解決策

### 1. フロントエンドの修正

**ファイル**: `src/services/api/authApi.ts`

不要なAPI呼び出しを削除し、クライアントサイドでのトークンクリアのみに変更：

```typescript
export const logout = async (): Promise<void> => {
  // TokenManagerを使用してクリーンアップ
  tokenManager.clearTokens();

  // 開発環境での自動認証を無効化するフラグを設定
  sessionStorage.setItem('user-logged-out', 'true');

  console.log('🚪 Logout completed - tokens cleared');
};
```

### 2. バックエンドエンドポイントの追加（オプション）

**ファイル**: `api/auth/logout.ts`

将来的なセッション管理のために、ログアウトエンドポイントを準備：

- POSTメソッドで `/api/auth/logout` にアクセス
- トークン検証とログ記録が可能
- 現在は使用されていないが、必要に応じて有効化可能

## 結果

- 404エラーが解消
- ログアウト機能は正常に動作
- クライアントサイドでトークンが適切にクリア

## タスク数制限の警告について

「タスク数が制限を超えています。最初の15件のみを分析します（全28件中）」

この警告は**期待通りの動作**です：

- Gemini API無料プランのレート制限対策
- 15件を超えるタスクは自動的に制限
- フォールバック分類により基本的な分類は保証

### 対処法

1. 重要なタスクを優先的に管理（最初の15件に配置）
2. 完了したタスクは定期的に削除
3. 必要に応じて手動で「再分析」ボタンを使用
