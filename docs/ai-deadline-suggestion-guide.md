# AI期限提案機能ガイド

## 概要

タスク追加時にAIが自動的に適切な期限を提案する機能です。タスクの内容、優先度、推定時間などを分析して、現実的な期限を設定します。

## 機能の特徴

### 1. 手動期限提案

タスクフォームの期限入力欄にある「AI提案」ボタンをクリックすることで、AIが期限を提案します。

### 2. 自動期限提案（開発中）

「期限を自動提案」をONにすると、タスク名を入力した際に自動で期限を提案します。

### 3. インテリジェントな分析

以下の要素を考慮して期限を決定：

- **タスクの内容**: タイトルと説明から複雑さを推定
- **優先度**: 高優先度は短め、低優先度は長めに設定
- **タスクタイプ**: バグ修正は緊急、計画タスクは余裕を持って
- **推定作業時間**: 作業量に応じた現実的な期限
- **営業日考慮**: 週末を避けて翌営業日に調整

## 使い方

### 手動で期限を提案

1. タスク追加フォームを開く
2. タスク名を入力
3. 期限欄の「AI提案」ボタンをクリック
4. AIが提案した期限を確認
5. 必要に応じて手動で調整

### 自動期限提案を有効化

1. タスク追加フォームの「期限を自動提案」スイッチをON
2. タスク名を入力（10文字以上）
3. 自動的に期限が設定される

## AIプロバイダー別の特徴

| プロバイダー | 精度 | 速度 | 特徴               |
| ------------ | ---- | ---- | ------------------ |
| Gemini       | 高   | 速い | バランスが良い     |
| Claude       | 最高 | 普通 | より詳細な分析     |
| OpenAI       | 高   | 遅い | 複雑なタスクに強い |
| Ollama       | 中   | 速い | ローカル実行で高速 |

## 期限設定の目安

### タスクタイプ別

| タスクタイプ | 推奨期限 | 理由                       |
| ------------ | -------- | -------------------------- |
| バグ修正     | 1-2日    | 緊急対応が必要             |
| 機能追加     | 1-2週間  | 開発とテストに時間が必要   |
| 調査・検討   | 2-4週間  | 情報収集と分析に時間が必要 |
| 定期タスク   | 1週間    | 定期的な実行を考慮         |

### 優先度別

| 優先度    | 推奨期限 | 調整         |
| --------- | -------- | ------------ |
| 最高（5） | 1-3日    | 即座に着手   |
| 高（4）   | 3-5日    | 早めの対応   |
| 中（3）   | 1-2週間  | 標準的な期限 |
| 低（2）   | 2-3週間  | 余裕を持って |
| 最低（1） | 3-4週間  | 他タスク優先 |

## 高度な使い方

### 期限提案のカスタマイズ

AIの提案をより精度高くするために：

1. **詳細な説明を追加**: タスクの背景や要件を記載
2. **推定時間を設定**: 作業時間の見積もりを入力
3. **優先度を正確に**: ビジネスインパクトに基づいて設定

### バッファ時間の考慮

AIは自動的に以下のバッファを含めます：

- 予期せぬ問題への対処時間（20%）
- レビューとフィードバック時間
- 他タスクとの調整時間

## トラブルシューティング

### Q: 期限が短すぎる/長すぎる

**原因**: タスクの複雑さが正しく評価されていない

**対策**:

1. タスクの説明をより詳細に記載
2. 推定作業時間を明示的に設定
3. 手動で期限を調整

### Q: AI提案ボタンが表示されない

**原因**: AIプロバイダーが設定されていない

**対策**:

1. 環境変数にAPIキーを設定
2. 4象限タブでプロバイダーを選択

### Q: 提案に時間がかかる

**原因**: APIの応答遅延またはレート制限

**対策**:

1. Ollama（ローカルLLM）を使用
2. キャッシュをクリアして再試行

## ベストプラクティス

### 1. タスクの明確化

- 具体的なタスク名を使用
- 成果物や完了条件を明記
- 依存関係を説明に含める

### 2. 現実的な期限設定

- AIの提案を参考にしつつ、自分の状況を考慮
- バッファ時間を意識的に確保
- 定期的に期限を見直す

### 3. フィードバックループ

- 実際の所要時間を記録
- 期限の精度を振り返る
- パターンを学習してより良い見積もりへ
