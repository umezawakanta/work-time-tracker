# AIタスクタイプ提案機能ガイド

## 概要

タスク追加時にAIが自動的にタスクのタイプを分析・提案する機能です。タスクのタイトルと説明から、最適なタイプを自動で判定します。

## 対応タイプ

- 👤 **Personal** (個人) - 家事、趣味、プライベートな予定
- 💼 **Work** (仕事) - 業務、会議、プロジェクト関連
- 📚 **Study** (学習) - 勉強、講座、スキルアップ
- 🏃 **Health** (健康) - 運動、通院、健康管理
- 📥 **Input** (インプット) - アイデア収集、情報収集
- 📤 **Output** (アウトプット) - 成果物作成、実行
- 📋 **Other** (その他) - 上記に分類されないタスク

## 使用方法

### 手動でタイプを提案

1. タスクのタイトルを入力
2. タイプ選択欄の「AI提案」ボタンをクリック
3. AIが分析してタイプを自動設定

### 自動タイプ提案を有効化

1. タスク追加フォームのプレミアム設定セクションを開く
2. 「タイプを自動提案」スイッチをONにする
3. タスクタイトルを5文字以上入力すると、1秒後に自動でタイプが提案される

## タイプ判定の仕組み

### AI分析（APIキー設定時）

1. タスクのタイトルと説明を分析
2. キーワード、文脈、タスクの性質を総合的に判断
3. 確信度とともにタイプを提案

### ヒューリスティック分析（フォールバック）

APIキーが設定されていない場合や、API呼び出しに失敗した場合は、キーワードマッチングによる自動分類を行います。

#### キーワード例

- **Work**: 会議、ミーティング、資料、報告、プレゼン、業務、プロジェクト
- **Personal**: 買い物、掃除、洗濯、料理、家事、家族、友達、趣味
- **Study**: 勉強、学習、講座、資格、スキル、研修、試験
- **Health**: 運動、ジム、ランニング、散歩、病院、通院、健康

## 設定の永続化

- 自動タイプ提案の設定は`localStorage`に保存され、次回以降も維持されます
- キー: `autoSuggestType`

## トラブルシューティング

### タイプが提案されない

- タスクタイトルが短すぎる（5文字未満）
- APIキーが正しく設定されていない
- レート制限に達している

### 提案精度を上げるには

- タスクタイトルを具体的に記述する
- 説明欄も活用する
- プレミアム機能の「AI分析」を併用する

## 実装詳細

### コンポーネント構成

```
src/
├── services/ai/
│   └── QuadrantClassificationService.ts  # suggestTaskType()メソッド
├── components/dailyToDoReminder/todo/
│   ├── hooks/
│   │   └── useTodoForm.ts               # タイプ提案ロジック統合
│   ├── components/
│   │   └── TaskTypeSelect.tsx           # タイプ選択UI with AI提案ボタン
│   └── AddTodoForm.tsx                  # メインフォーム
```

### 主要メソッド

- `QuadrantClassificationService.suggestTaskType()` - AIによるタイプ提案
- `useTodoForm.handleSuggestType()` - UIからの提案実行
- `useTodoForm.toggleAutoSuggestType()` - 自動提案の有効/無効切り替え
