# 優先度フィルター機能ガイド

## 概要

多数のタスクがある場合に、優先度でフィルタリングしてから4象限分析を実行できる機能です。これにより、重要なタスクのみに絞って効率的に分析できます。

## 機能説明

### 優先度フィルターの有効化

1. **4象限タブ**を開く
2. **「優先度フィルター」チェックボックス**をオンにする
3. 分析したい優先度レベルを選択：
   - 🔴 **高**: 優先度の高いタスク
   - 🟡 **中**: 中程度の優先度のタスク
   - ⚪ **低**: 優先度の低いタスク

### フィルタリングの動作

- **複数選択可能**: 高・中・低を自由に組み合わせて選択
- **リアルタイム反映**: チェックボックスを変更すると即座にフィルター適用
- **件数表示**: フィルター適用後のタスク数が表示される

## 使用シナリオ

### 1. 大量タスクの効率的分析

**問題**: 50件以上のタスクがある場合、全て分析すると時間がかかる

**解決策**:

1. 優先度フィルターを有効化
2. 「高」のみにチェック
3. 重要なタスクのみを分析

### 2. 段階的な分析

**アプローチ**:

1. まず「高」優先度のタスクを分析
2. 次に「中」優先度を追加して分析
3. 最後に「低」も含めて全体分析

### 3. APIコスト削減

**メリット**:

- 分析対象を絞ることでAPIコール数を削減
- 特にOpenAI使用時のコスト削減に効果的

## 優先度の判定ロジック

### 数値優先度（1-5）の場合

- **4-5**: 高優先度
- **2-3**: 中優先度
- **1**: 低優先度

### 文字列優先度の場合

- **"high", "高"**: 高優先度
- **"medium", "中"**: 中優先度
- **"low", "低"**: 低優先度

### デフォルト

- 優先度が設定されていないタスクは「中」として扱われる

## 推奨設定

### タスク数別の推奨フィルター

| タスク数 | 推奨フィルター        | 理由               |
| -------- | --------------------- | ------------------ |
| 10件以下 | フィルターなし        | 全件分析可能       |
| 11-30件  | 高・中を選択          | 重要タスクに集中   |
| 31-50件  | 高のみ選択            | 最重要タスクを優先 |
| 50件以上 | 高のみ → 段階的に追加 | 効率的な段階分析   |

### AIプロバイダー別の推奨

| プロバイダー | 推奨フィルター             | 理由                 |
| ------------ | -------------------------- | -------------------- |
| Gemini       | フィルター不要（20件まで） | 無料枠が大きい       |
| Claude       | 高・中（15件程度）         | バランス重視         |
| OpenAI       | 高のみ（5件以下）          | コスト最適化         |
| Ollama       | フィルター不要（50件まで） | ローカル実行で無制限 |

## パフォーマンスへの影響

### メリット

- ✅ **分析時間短縮**: タスク数を絞ることで高速化
- ✅ **精度向上**: 重要タスクに集中できる
- ✅ **コスト削減**: APIコール数の削減
- ✅ **メモリ使用量削減**: 処理データ量の削減

### デメリット

- ⚠️ **全体像の欠如**: フィルターした分のタスクが分析から除外
- ⚠️ **手動操作必要**: フィルター設定の手間

## トラブルシューティング

### Q: フィルター後のタスクが0件になる

A: 選択した優先度のタスクが存在しないか、全てのタスクが完了済みの可能性があります。

### Q: フィルターが効かない

A: タスクの優先度フィールドが正しく設定されているか確認してください。

### Q: 優先度が正しく判定されない

A: タスクの優先度フィールド名（priority, priorityLevel等）と値の形式を確認してください。

## ベストプラクティス

1. **定期的な見直し**
   - 週次で低優先度タスクも含めて全体分析
   - 日次では高優先度のみに集中

2. **プロバイダーとの組み合わせ**
   - コスト重視: OpenAI + 高優先度フィルター
   - バランス: Claude + 高・中フィルター
   - 全体分析: Ollama + フィルターなし

3. **タスク整理との連携**
   - 優先度未設定のタスクを定期的に確認
   - 優先度の見直しと更新

## まとめ

優先度フィルター機能により：

- 🎯 **効率的な分析**: 重要タスクに集中
- 💰 **コスト最適化**: API使用量の削減
- ⚡ **高速処理**: 分析時間の短縮
- 📊 **段階的分析**: 優先度別の段階的アプローチ

多数のタスクを抱える場合の必須機能として活用してください。
