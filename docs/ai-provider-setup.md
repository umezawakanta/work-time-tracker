# AI プロバイダー設定ガイド

## 概要

Work Time Trackerの4象限マトリックス機能では、タスク分析にGemini AI、Claude AI、またはOpenAI GPT-4を選択して使用できます。

## 対応AIプロバイダー

### 1. Google Gemini AI

- **モデル**: Gemini 2.0 Flash
- **特徴**: 高速レスポンス、無料枠あり
- **無料枠**: 1分間に60リクエスト、1日1500リクエスト

### 2. Anthropic Claude AI

- **モデル**: Claude 3 Haiku
- **特徴**: 高精度、コスト効率的
- **料金**: 従量課金制（無料枠なし）

### 3. OpenAI GPT-4

- **モデル**: GPT-4 Turbo
- **特徴**: 最高精度、業界標準
- **料金**: 従量課金制（無料枠なし、高コスト）

### 4. Ollama (ローカルLLM) 🆕

- **モデル**: Llama 3.2, Mistral, Phi3 など選択可能
- **特徴**: 完全無料、プライバシー保護、オフライン対応
- **料金**: 完全無料（ローカル実行）
- **要件**: 8GB以上のRAM、Ollamaのインストール

## セットアップ手順

### 1. Gemini API キーの取得

1. [Google AI Studio](https://makersuite.google.com/app/apikey)にアクセス
2. Googleアカウントでログイン
3. 「Create API Key」をクリック
4. APIキーをコピー

### 2. Claude API キーの取得

1. [Anthropic Console](https://console.anthropic.com/)にアクセス
2. アカウントを作成またはログイン
3. 「API Keys」セクションに移動
4. 「Create Key」をクリック
5. APIキーをコピー

### 3. OpenAI API キーの取得

1. [OpenAI Platform](https://platform.openai.com/api-keys)にアクセス
2. アカウントを作成またはログイン
3. 「+ Create new secret key」をクリック
4. キーに名前を付ける（例：work-time-tracker）
5. APIキーをコピー（二度と表示されないので注意）

### 4. Ollama のセットアップ

1. [Ollama公式サイト](https://ollama.com/download)からインストーラーをダウンロード
2. インストール後、ターミナルで以下を実行：

   ```bash
   # Ollamaサービスを起動（Windowsは自動起動）
   ollama serve

   # 推奨モデルをダウンロード
   ollama pull llama3.2:3b
   ```

3. 詳細な手順は[Ollamaセットアップガイド](./ollama-setup-guide.md)を参照

### 5. 環境変数の設定

プロジェクトルートに`.env`ファイルを作成し、以下の内容を追加：

```bash
# Gemini API Key (推奨 - 無料枠あり)
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# Claude API Key (オプション)
VITE_CLAUDE_API_KEY=your_claude_api_key_here

# OpenAI API Key (オプション)
VITE_OPENAI_API_KEY=your_openai_api_key_here

# Ollama Model (オプション - デフォルト: llama3.2:3b)
VITE_OLLAMA_MODEL=llama3.2:3b
```

### 5. 自動設定スクリプト

#### Windows

```batch
scripts\setup-ai-providers.bat
```

#### Mac/Linux

```bash
chmod +x scripts/setup-ai-providers.sh
./scripts/setup-ai-providers.sh
```

## アプリケーションでの使用方法

### AIプロバイダーの切り替え

1. タスク管理センターの「4象限」タブを開く
2. 右上のAIプロバイダー選択ドロップダウンをクリック
3. 使用したいAIプロバイダーを選択
4. 「再分析」ボタンをクリックして新しいプロバイダーで分析を実行

### UIでの表示

- **✨ Google Gemini**: Gemini AIを使用
- **🤖 Anthropic Claude**: Claude AIを使用
- **🧠 OpenAI GPT-4**: GPT-4を使用
- **🦙 ローカルLLM (Ollama)**: Ollamaを使用
- **(未設定)**: APIキーが設定されていないプロバイダー
- **(未接続)**: Ollamaサーバーに接続できない

## トラブルシューティング

### APIキーが認識されない

1. `.env`ファイルが正しい場所にあるか確認
2. キーの前後に余分なスペースがないか確認
3. アプリケーションを再起動

### レート制限エラー

1. 分析するタスク数を減らす
2. キャッシュ機能を活用
3. 異なるプロバイダーに切り替える

### 分析が失敗する

1. APIキーの有効性を確認
2. インターネット接続を確認
3. ブラウザコンソールでエラーを確認
4. OpenAIの場合、クレジット残高を確認

## セキュリティに関する注意

- APIキーを公開リポジトリにコミットしない
- `.gitignore`に`.env`ファイルが含まれていることを確認
- 本番環境では環境変数を安全に管理
- OpenAI APIキーは特に慎重に扱う（高額な料金が発生する可能性）

## キャッシュ機能

- 一度分析したタスクはキャッシュされ、再分析時に高速表示
- プロバイダー間でキャッシュは共有される
- ゴミ箱アイコンでキャッシュをクリア可能

## 推奨設定

### 開発環境

- **推奨**: Ollama（完全無料・プライバシー保護）
- クラウド利用: Gemini（無料枠があるため）
- バランス重視: Claude
- 最高精度テスト: GPT-4

### 本番環境

- **機密データ**: Ollama（ローカル完結）
- **大量タスク**: Gemini（コスト効率）
- **標準利用**: Claude（バランス）
- **重要な分析**: GPT-4（精度重視）

## API料金の目安

### Gemini

- 無料枠: 1日1500リクエストまで無料
- 超過分: $0.00025/1000文字

### Claude (Haiku)

- 入力: $0.25/100万トークン
- 出力: $1.25/100万トークン
- 平均的なタスク分析: 約$0.0002/タスク

### GPT-4 Turbo

- 入力: $10/100万トークン
- 出力: $30/100万トークン
- 平均的なタスク分析: 約$0.015/タスク

### Ollama

- **完全無料**: ローカル実行のため料金なし
- 必要なのはハードウェアリソースのみ
