## 🔄 統合フロー

### 1. ページアクティビティ → バッジ進捗

```
ユーザーアクション（ページ操作）
↓
PageSyncSystem（アクティビティ記録）
↓
BadgeRequirement（要件更新計算）
↓
BadgeProgress（進捗率更新）
↓
WeeklyPlan（週次計画への反映）
```

### 2. サイバーセキュリティ学習 → 全体統合

```
週次学習セッション（時間記録）
↓
WeeklyWorkPlanningService（進捗管理）
↓
ComprehensivePageSyncSystem（全ページ同期）
↓
BadgeManagementDashboard（統合表示）
```

### 3. バッジ完了予測 → 計画調整

```
現在進捗データ（リアルタイム）
↓
機械学習予測（完了時期算出）
↓
週次計画調整（リソース配分）
↓
推奨アクション（最適化提案）
```
