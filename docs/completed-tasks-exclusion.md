# 完了済みタスクの除外機能

## 2025年1月16日 実装

### 概要

4象限マトリックス（アイゼンハワーマトリックス）の分析対象から、完了済みタスクを自動的に除外する機能を実装しました。

### 実装内容

#### 1. タスクフィルタリング

```typescript
// 完了済みタスクをフィルタリング
const incompleteTasks = tasks.filter((task) => {
  // 様々なタスク形式に対応
  return task && task._id && !task.completed && !task.isCompleted && task.status !== 'completed';
});
```

#### 2. 対応するタスク形式

以下のいずれかの条件に該当するタスクを「完了済み」として除外：

- `task.completed === true`
- `task.isCompleted === true`
- `task.status === 'completed'`

#### 3. UI の改善

##### ヘッダー表示

- 未完了タスク数と完了済みタスク数を表示
- 例：「（未完了: 15件 / 完了済み: 12件）」

##### 通知メッセージ

- **タスク数制限時**：

  ```
  未完了タスク20件中、最初の15件を分析しました（完了済み5件は除外）
  ```

- **通常の分析完了時**：
  ```
  4象限分析完了: 未完了10件を分類（完了済み8件は除外）
  ```

##### ローディング表示

- 分析中のタスク数を表示：
  ```
  Gemini AIが未完了タスク15件を分析しています
  ```

### 使用上の注意

1. **完了タスクの扱い**
   - 完了済みタスクは分析されません
   - 完了タスクの統計は別途表示されます

2. **タスク数の計算**
   - 15件の制限は未完了タスクのみカウント
   - 完了済みタスクは制限に含まれません

3. **再分析**
   - タスクを完了にした後、再分析で反映
   - 自動的に除外されます
