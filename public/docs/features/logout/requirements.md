ログアウト 要件定義書
=================

最終更新: 2025-08-30

目的
----
- 認証済みユーザーが安全にセッションを終了できること。

スコープ
------
- UI: ヘッダー右上のログアウトボタン（`src/components/layout/Layout.tsx`）
- バックグラウンド: `authApi.logout()` によりトークン破棄と状態クリア

要件
--
- 1クリックでトークンを完全削除し、未認証状態に遷移する
- 未ログイン時には表示されない
- 失敗時でも最終的にクライアント状態はクリアされる

API
--
-（現状）サーバ側無効化は任意。`/api/auth/logout` はログ記録中心。クライアント側削除が必須。

完了条件
------
- クリックで確実に未認証状態になり、`/login` へ誘導可能
- 管理者/一般ユーザーともに同じ挙動
