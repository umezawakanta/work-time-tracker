ログアウト 基本設計書
=================

最終更新: 2025-08-30

概要
----
ヘッダー右端のボタンから `authApi.logout()` を呼び、`TokenManager.clearTokens()` を実行。必要に応じて `/login` に遷移。

UI/動作
-----
- コンポーネント: `src/components/layout/Layout.tsx`（ユーザー情報横のボタン）
- クリック時: クライアントのトークン/セッション情報を削除し、`sessionStorage.user-logged-out = true` を設定
- 遷移: `/login`（stateでログアウトメッセージを渡すことも可）

エラーハンドリング
------------
- サーバ連携が失敗しても、クライアント側のトークンは必ず消去して未認証状態にする

セキュリティ
--------
- 二重送信防止、クリック中は非活性

完了条件（基本設計）
----------------
- クリックで確実に未認証化し、再読込しても状態が復帰しないことを確認
