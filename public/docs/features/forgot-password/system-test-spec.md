# パスワードリセット機能 総合試験仕様書

## 機能概要
パスワードを忘れたユーザーがメールアドレスを使用してパスワードをリセットする機能

## 試験環境
- 本番環境: https://work-time-tracker-five.vercel.app
- テスト環境: http://localhost:3000

## 前提条件
1. 有効なユーザーアカウントが登録済み
2. メール送信機能が正常に動作している
3. MongoDB接続が正常に動作している

## 試験項目

### 1. パスワード忘れページ表示
- [ ] `/forgot-password`にアクセスできる
- [ ] ページタイトル「パスワードをお忘れですか？」が表示される
- [ ] メールアドレス入力フィールドが表示される
- [ ] 送信ボタンが表示される
- [ ] ログインページへのリンクが表示される

### 2. メールアドレス入力・バリデーション
- [ ] 空のメールアドレスで送信時にエラーメッセージが表示される
- [ ] 無効なメール形式で送信時にエラーメッセージが表示される
- [ ] 有効なメール形式で入力時にチェックマークが表示される
- [ ] メールアドレス入力中にエラーメッセージがクリアされる

### 3. パスワードリセットメール送信
- [ ] 登録済みメールアドレスで送信時に成功メッセージが表示される
- [ ] 未登録メールアドレスで送信時に成功メッセージが表示される（セキュリティのため）
- [ ] 送信後、成功ページに遷移する
- [ ] 送信ボタンが送信中は無効化される
- [ ] 送信中はローディングスピナーが表示される

### 4. 成功ページ表示
- [ ] 送信成功時に成功ページが表示される
- [ ] 送信したメールアドレスが表示される
- [ ] メール確認の案内が表示される
- [ ] 別のメールアドレスで試すボタンが表示される
- [ ] ログインページに戻るボタンが表示される

### 5. パスワードリセット確認ページ
- [ ] 有効なトークンでアクセス時にパスワード入力フォームが表示される
- [ ] 無効なトークンでアクセス時にエラーメッセージが表示される
- [ ] 期限切れトークンでアクセス時にエラーメッセージが表示される
- [ ] トークン検証中はローディングスピナーが表示される

### 6. パスワード入力・バリデーション
- [ ] パスワード入力フィールドが表示される
- [ ] パスワード確認入力フィールドが表示される
- [ ] パスワード表示/非表示切り替えが動作する
- [ ] 8文字未満のパスワードでエラーメッセージが表示される
- [ ] 要件を満たさないパスワードでエラーメッセージが表示される
- [ ] パスワードと確認が一致しない場合にエラーメッセージが表示される

### 7. パスワードリセット実行
- [ ] 有効なパスワードで送信時に成功メッセージが表示される
- [ ] パスワードリセット後、成功ページに遷移する
- [ ] 成功ページからログインページに遷移できる
- [ ] 新しいパスワードでログインできる

### 8. エラーハンドリング
- [ ] ネットワークエラー時に適切なエラーメッセージが表示される
- [ ] サーバーエラー時に適切なエラーメッセージが表示される
- [ ] 無効なトークン時に適切なエラーメッセージが表示される
- [ ] 期限切れトークン時に適切なエラーメッセージが表示される

### 9. セキュリティ
- [ ] トークンは24時間で期限切れになる
- [ ] 使用済みトークンは無効になる
- [ ] パスワードは適切にハッシュ化される
- [ ] セキュリティヘッダーが設定されている

### 10. レスポンシブデザイン
- [ ] モバイルデバイスで適切に表示される
- [ ] タブレットデバイスで適切に表示される
- [ ] デスクトップで適切に表示される

## 試験データ
- テスト用ユーザーアカウント: 有効なメールアドレスとパスワード
- テスト用メールアドレス: 実際にメールを受信できるアドレス
- テスト用トークン: 有効なリセットトークン

## 期待結果
- すべての試験項目が合格する
- 本番環境でMongoDBと正常に連携する
- モックやダミー処理が含まれていない
- エラーが発生しない
- メール送信が正常に動作する
- セキュリティ要件を満たす

## 備考
- メール送信は実際のSMTPサーバーを使用
- トークンは暗号学的に安全な乱数で生成
- パスワードはbcryptでハッシュ化
- セキュリティのため、存在しないメールアドレスでも成功レスポンスを返す
