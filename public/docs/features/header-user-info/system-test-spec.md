# ヘッダーユーザー情報機能 システムテスト仕様書

## 概要
ヘッダー右側に表示されるユーザー情報（表示名、メールアドレス、アバター）の表示と動作をテストします。

## テスト環境
- **本番環境**: https://work-time-tracker-five.vercel.app
- **テスト日時**: 2025-09-06
- **テスト担当者**: システムテスト担当者

## 前提条件
- ユーザーがログイン済みであること
- ヘッダーユーザー情報機能が`complete`ステータスであること

## テストケース

### TC-001: ユーザー情報表示の基本動作
**目的**: ログイン済みユーザーの情報がヘッダーに正しく表示されることを確認

**手順**:
1. アプリケーションにログインする
2. ヘッダー右側のユーザー情報エリアを確認する

**期待結果**:
- ユーザーアバター（グラデーション背景の円形アイコン）が表示される
- ユーザーの表示名またはユーザー名が表示される
- ユーザーのメールアドレスが表示される
- 設定ボタン（歯車アイコン）が表示される

### TC-002: 表示名の優先順位
**目的**: ユーザー情報の表示名が正しい優先順位で表示されることを確認

**テストデータ**:
- ケース1: displayName, username, name, email すべて設定済み
- ケース2: displayName のみ設定済み
- ケース3: username のみ設定済み
- ケース4: name のみ設定済み
- ケース5: email のみ設定済み

**手順**:
1. 各ケースのテストデータでユーザーを作成
2. ログインしてヘッダーの表示名を確認

**期待結果**:
- ケース1: displayName が表示される
- ケース2: displayName が表示される
- ケース3: username が表示される
- ケース4: name が表示される
- ケース5: email の @ より前の部分が表示される

### TC-003: レスポンシブ表示
**目的**: 画面サイズに応じてユーザー情報が適切に表示されることを確認

**手順**:
1. デスクトップ画面（1024px以上）でヘッダーを確認
2. タブレット画面（768px-1023px）でヘッダーを確認
3. モバイル画面（767px以下）でヘッダーを確認

**期待結果**:
- デスクトップ: アバター、表示名、メールアドレス、設定ボタンがすべて表示される
- タブレット: アバター、表示名、メールアドレス、設定ボタンがすべて表示される
- モバイル: アバターと設定ボタンのみ表示され、表示名とメールアドレスは非表示

### TC-004: ダークモード対応
**目的**: ダークモードでユーザー情報が適切に表示されることを確認

**手順**:
1. ライトモードでヘッダーのユーザー情報を確認
2. ダークモードに切り替え
3. ヘッダーのユーザー情報を確認

**期待結果**:
- ライトモード: 適切な色で表示される
- ダークモード: 適切な色で表示される
- ホバー効果が両モードで動作する

### TC-005: ホバー効果
**目的**: ユーザー情報エリアのホバー効果が正しく動作することを確認

**手順**:
1. ユーザー情報エリアにマウスをホバーする
2. 設定ボタンにマウスをホバーする

**期待結果**:
- ユーザー情報エリア: 背景色が変化する
- 設定ボタン: 背景色が変化する
- スムーズなトランジション効果が適用される

### TC-006: 長いテキストの処理
**目的**: 長い表示名やメールアドレスが適切に処理されることを確認

**テストデータ**:
- 表示名: 50文字の長い文字列
- メールアドレス: 長いドメイン名のメールアドレス

**手順**:
1. 長いテキストのテストデータでユーザーを作成
2. ログインしてヘッダーの表示を確認

**期待結果**:
- 表示名: 適切に省略表示（...）される
- メールアドレス: 適切に省略表示（...）される
- レイアウトが崩れない

### TC-007: 未ログイン状態
**目的**: 未ログイン状態でユーザー情報が表示されないことを確認

**手順**:
1. ログアウトする
2. ヘッダー右側を確認する

**期待結果**:
- ユーザー情報エリアが表示されない
- ログアウトボタンのみ表示される

### TC-008: ユーザー情報の更新
**目的**: ユーザー情報が更新された際にヘッダー表示が即座に反映されることを確認

**手順**:
1. プロフィールページでユーザー情報を更新
2. ヘッダーの表示を確認

**期待結果**:
- 更新された情報が即座にヘッダーに反映される
- ページリロードなしで更新される

**期待結果**:

## パフォーマンステスト

### PT-001: 表示速度
**目的**: ヘッダーユーザー情報の表示速度を確認

**手順**:
1. ページロード時間を測定
2. ユーザー情報の表示時間を測定

**期待結果**:

## アクセシビリティテスト

### AT-001: キーボードナビゲーション
**目的**: キーボードのみでユーザー情報エリアにアクセスできることを確認

**手順**:
1. Tabキーでユーザー情報エリアにフォーカスを移動
2. Enterキーでアクションを実行

**期待結果**:
- キーボードでフォーカス可能
- 適切なフォーカス表示
- Enterキーでアクション実行可能

### AT-002: スクリーンリーダー対応
**目的**: スクリーンリーダーでユーザー情報が適切に読み上げられることを確認

**手順**:
1. スクリーンリーダーでユーザー情報エリアを読み上げ
2. 表示名とメールアドレスが適切に読み上げられることを確認

**期待結果**:
- 適切なaria-labelが設定されている
- 表示名とメールアドレスが正しく読み上げられる
