# ヘッダーユーザー情報機能 運用マニュアル

## 概要
ヘッダー右側に表示されるユーザー情報（表示名、メールアドレス、アバター）の運用に関する情報をまとめています。

## 機能概要
- **機能名**: ヘッダーユーザー情報
- **機能ID**: `header-user-info`
- **パス**: `/_bg/header-user-info`
- **カテゴリ**: コア
- **ステータス**: 完成
- **優先度**: P0
- **リリース日**: 2025-09-06

## 表示内容
### ユーザーアバター
- グラデーション背景（青から紫）
- ユーザーアイコン
- 8x8の円形表示
- シャドウ効果付き

### ユーザー情報
- **表示名**: 以下の優先順位で表示
  1. `displayName`
  2. `username`
  3. `name`
  4. `email`の@より前の部分
  5. デフォルト「ユーザー」
- **メールアドレス**: 完全なメールアドレスを表示

### 設定ボタン
- 歯車アイコン
- ホバー効果付き
- 8x8のサイズ

## レスポンシブ対応
### デスクトップ（1024px以上）
- アバター、表示名、メールアドレス、設定ボタンすべて表示

### タブレット（768px-1023px）
- アバター、表示名、メールアドレス、設定ボタンすべて表示

### モバイル（767px以下）
- アバターと設定ボタンのみ表示
- 表示名とメールアドレスは非表示

## 表示条件
- ユーザーがログイン済みであること
- 機能のステータスが`complete`であること
- `user`オブジェクトが存在すること

## 技術仕様
### 依存関係
- `useAuth`フック（ユーザー情報取得）
- `getFeatureByPath`関数（機能ステータス確認）

### スタイリング

### アクセシビリティ

2. **パフォーマンス**
   - 表示速度（1秒以内）

## トラブルシューティング
### よくある問題

#### 1. ユーザー情報が表示されない
**症状**: ヘッダーにユーザー情報が表示されない

**原因**:
- ユーザーがログインしていない
- 機能のステータスが`complete`でない
- `user`オブジェクトが`null`または`undefined`

**対処法**:
1. ユーザーのログイン状態を確認
2. 機能のステータスを確認
3. `useAuth`フックの動作を確認

#### 2. 表示名が正しく表示されない
**症状**: 期待する表示名が表示されない

**原因**:
- ユーザーデータの構造が期待と異なる
- 表示名の優先順位ロジックに問題

**対処法**:
1. ユーザーデータの構造を確認
2. 表示名の優先順位ロジックを確認
3. デバッグログでユーザーデータを確認

#### 3. レスポンシブ表示が崩れている
**症状**: 画面サイズに応じた表示が正しく動作しない

**原因**:
- Tailwind CSSのブレークポイント設定の問題
- CSSクラスの適用ミス

**対処法**:
1. ブレークポイントの設定を確認
2. CSSクラスの適用を確認
3. ブラウザの開発者ツールでスタイルを確認

#### 4. ホバー効果が動作しない
**症状**: マウスホバー時の効果が表示されない

**原因**:
- CSSクラスの適用ミス
- JavaScriptのイベントハンドリングの問題

**対処法**:
1. ホバー用のCSSクラスを確認
2. イベントハンドリングの実装を確認
3. ブラウザの開発者ツールでスタイルを確認
