# 利用規約機能 総合試験仕様書

## 機能概要
サービス利用規約の表示機能

## 試験環境
- 本番環境: https://work-time-tracker-five.vercel.app
- テスト環境: http://localhost:3000

## 前提条件
1. ブラウザが正常に動作している
2. インターネット接続が正常である
3. 利用規約機能が有効化されている

## 試験項目

### 1. 基本表示機能
- [ ] 利用規約ページにアクセスできる（`/terms`）
- [ ] ページタイトル「利用規約」が表示される
- [ ] 最終更新日（2025年9月7日）が表示される
- [ ] Work Time Trackerの記載が表示される
- [ ] 利用規約の内容が正しく表示される

### 2. 利用規約内容の表示
- [ ] 第1条（適用）が表示される
- [ ] 第2条（利用登録）が表示される
- [ ] 第3条（ユーザーIDおよびパスワードの管理）が表示される
- [ ] 第4条（禁止事項）が表示される
- [ ] 第5条（本サービスの提供の停止等）が表示される
- [ ] 第6条（利用制限および登録抹消）が表示される
- [ ] 第7条（退会）が表示される
- [ ] 第8条（保証の否認および免責事項）が表示される
- [ ] 第9条（サービス内容の変更等）が表示される
- [ ] 第10条（利用規約の変更）が表示される
- [ ] 第11条（個人情報の取扱い）が表示される
- [ ] 第12条（通知または連絡）が表示される
- [ ] 第13条（権利義務の譲渡の禁止）が表示される
- [ ] 第14条（準拠法・裁判管轄）が表示される

### 3. 重要な表示要素
- [ ] 重要事項のハイライト表示（黄色背景）が表示される
- [ ] お問い合わせ情報が表示される
- [ ] 制定日（2025年9月7日）が表示される
- [ ] 各条項の見出しが適切に表示される
- [ ] 箇条書きが正しく表示される

### 4. ナビゲーション機能
- [ ] 「ホームに戻る」ボタンが表示される
- [ ] 「ホームに戻る」ボタンが正常に動作する
- [ ] 「アカウント作成」ボタンが表示される
- [ ] 「アカウント作成」ボタンが正常に動作する
- [ ] 「プライバシーポリシー」ボタンが表示される
- [ ] 「プライバシーポリシー」ボタンが正常に動作する

### 5. レスポンシブデザイン
- [ ] デスクトップ表示で正常に表示される
- [ ] タブレット表示で正常に表示される
- [ ] モバイル表示で正常に表示される
- [ ] 横スクロールが発生しない
- [ ] テキストが適切に折り返される

### 6. アクセシビリティ
- [ ] キーボード操作でナビゲーションできる
- [ ] スクリーンリーダーで内容が読み上げられる
- [ ] 適切な見出し構造になっている
- [ ] コントラスト比が適切である
- [ ] フォーカス表示が適切である

### 7. ダークモード対応
- [ ] ダークモードで正常に表示される
- [ ] テキストの可読性が保たれる
- [ ] 背景色が適切に切り替わる
- [ ] ボーダー色が適切に切り替わる

### 8. フッターリンク
- [ ] フッターに「利用規約」リンクが表示される
- [ ] フッターの「利用規約」リンクが正常に動作する
- [ ] 利用規約が完成状態の場合のみ表示される

## 判定基準（合否）
- 上記すべてのケースが期待結果どおりであること
- 利用規約の内容が法的に適切であること
- ブラウザのコンソールに致命的エラーが出ていないこと
- ページの読み込み時間が3秒以内であること
- すべてのリンクが正常に動作すること

## 付記
- 利用規約の内容は法的な検証が必要
- 将来的に多言語対応を検討
- 利用規約の変更時は適切な通知機能の実装が必要
