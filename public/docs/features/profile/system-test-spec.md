# 👤 プロフィール機能 総合試験仕様書

## 機能概要
ユーザープロフィールの表示・編集・設定管理機能

## 試験環境
- 本番環境: https://work-time-tracker-five.vercel.app
- テスト環境: http://localhost:3000

## 前提条件
1. 有効なユーザーアカウントでログイン済み
2. プロフィール機能が有効化されている
3. ブラウザが正常に動作している

## 試験項目

### 1. 基本表示機能
- [ ] プロフィールページにアクセスできる（`/profile`）
- [ ] ページタイトル「ユーザープロフィール」が表示される
- [ ] 管理者権限がある場合は「管理者」バッジが表示される
- [ ] 5つのタブ（プロフィール、設定、通知、セキュリティ、セッション）が表示される
- [ ] ローディング状態が適切に表示される

### 2. プロフィールタブ
- [ ] 基本情報セクションが表示される
- [ ] 権限レベル（管理者/一般ユーザー）が表示される
- [ ] 名前フィールドが表示され、現在の値が入力されている
- [ ] メールアドレスフィールドが表示され、現在の値が入力されている
- [ ] 「更新」ボタンが表示される
- [ ] 一般ユーザーの場合、「管理者権限を付与（開発用）」ボタンが表示される
- [ ] 管理者の場合、「✓ 管理者権限が付与されています」メッセージが表示される

### 3. 設定タブ
- [ ] 基本設定セクションが表示される
- [ ] 言語選択（日本語/English）が動作する
- [ ] タイムゾーン選択（Asia/Tokyo/UTC/America/New_York）が動作する
- [ ] 通貨選択（JPY/USD/EUR）が動作する
- [ ] テーマ設定セクションが表示される
- [ ] テーマ選択（ライト/ダーク/システム設定に従う）が動作する
- [ ] アクセントカラー選択（ブルー/グリーン/パープル/レッド）が動作する
- [ ] アニメーションを減らすスイッチが動作する

### 4. 通知タブ
- [ ] 通知設定セクションが表示される
- [ ] メール通知スイッチが動作する
- [ ] プッシュ通知スイッチが動作する
- [ ] セキュリティアラートスイッチが動作する
- [ ] 週次ダイジェストスイッチが動作する
- [ ] タスクリマインダースイッチが動作する
- [ ] 各設定項目に適切な説明文が表示される

### 5. セキュリティタブ
- [ ] パスワード変更セクションが表示される
- [ ] 現在のパスワード入力フィールドが表示される
- [ ] 新しいパスワード入力フィールドが表示される
- [ ] パスワード確認入力フィールドが表示される
- [ ] パスワード表示/非表示切り替えが動作する
- [ ] パスワード強度インジケーターが表示される
- [ ] パスワード強度が適切に計算される（弱い/普通/強い）
- [ ] 「パスワードを変更」ボタンが表示される

### 6. セッションタブ
- [ ] アクティブセッション一覧が表示される
- [ ] 各セッションに以下の情報が表示される
  - [ ] デバイス情報
  - [ ] 場所情報
  - [ ] IPアドレス
  - [ ] 最終アクティビティ
  - [ ] 現在のセッションかどうか
- [ ] セッション終了ボタンが表示される
- [ ] 「他のすべてのセッションを終了」ボタンが表示される

### 7. プロフィール更新機能
- [ ] 名前を変更して更新できる
- [ ] メールアドレスを変更して更新できる
- [ ] 更新成功時にトースト通知が表示される
- [ ] 更新失敗時にエラーメッセージが表示される
- [ ] 更新後に最新のユーザー情報が表示される

### 8. パスワード変更機能
- [ ] 現在のパスワードが正しい場合、パスワード変更が成功する
- [ ] 現在のパスワードが間違っている場合、エラーメッセージが表示される
- [ ] 新しいパスワードが弱い場合、エラーメッセージが表示される
- [ ] パスワードと確認が一致しない場合、エラーメッセージが表示される
- [ ] パスワード変更成功時にトースト通知が表示される
- [ ] パスワード変更後にフォームがリセットされる

### 9. 管理者権限付与機能（開発用）
- [ ] 一般ユーザーの場合、管理者権限付与ボタンが表示される
- [ ] 管理者権限付与が成功する
- [ ] 権限付与後にユーザー情報が更新される
- [ ] 権限付与成功時にトースト通知が表示される
- [ ] 権限付与後に「管理者」バッジが表示される

### 10. セッション管理機能
- [ ] 個別セッションの終了が動作する
- [ ] 全セッション終了が動作する
- [ ] セッション終了後に一覧が更新される
- [ ] セッション終了成功時にトースト通知が表示される

### 11. レスポンシブデザイン
- [ ] デスクトップ表示で正常に表示される
- [ ] タブレット表示で正常に表示される
- [ ] モバイル表示で正常に表示される
- [ ] タブが適切に折り返される
- [ ] フォーム要素が適切に配置される

### 12. アクセシビリティ
- [ ] キーボード操作でナビゲーションできる
- [ ] スクリーンリーダーで内容が読み上げられる
- [ ] 適切なラベルが設定されている
- [ ] フォーカス表示が適切である
- [ ] コントラスト比が適切である

### 13. エラーハンドリング
- [ ] ネットワークエラー時に適切なメッセージが表示される
- [ ] バリデーションエラーが適切に表示される
- [ ] ローディング状態が適切に管理される
- [ ] エラー発生時にユーザーが操作を継続できる

## 判定基準（合否）
- 上記すべてのケースが期待結果どおりであること
- プロフィール情報が正確に表示・更新されること
- セキュリティ機能が適切に動作すること
- ブラウザのコンソールに致命的エラーが出ていないこと
- ページの読み込み時間が3秒以内であること
- すべてのフォームが適切にバリデーションされること

## 付記
- 管理者権限付与機能は開発環境でのみ使用
- 本番環境では適切な権限管理が必要
- 将来的にプロフィール画像アップロード機能を追加予定
- 通知設定は実際の通知システムと連携する必要がある
