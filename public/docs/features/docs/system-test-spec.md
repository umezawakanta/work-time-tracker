# 📄 ドキュメント機能 総合試験仕様書

## 機能概要
Markdownドキュメントの表示・検索・管理機能

## 試験環境
- 本番環境: https://work-time-tracker-five.vercel.app
- テスト環境: http://localhost:3000

## 前提条件
1. アプリケーションが正常に起動している
2. ドキュメント機能が有効化されている
3. ブラウザが正常に動作している

## 試験項目

### 1. ドキュメント一覧表示機能
- [ ] ドキュメントページにアクセスできる（`/docs`）
- [ ] ページタイトル「ドキュメント」が表示される
- [ ] ドキュメント一覧が表示される
- [ ] 各ドキュメントに以下の情報が表示される
  - [ ] タイトル
  - [ ] カテゴリバッジ
  - [ ] 説明文（最初の段落）
  - [ ] 最終更新日
  - [ ] ファイルサイズ
- [ ] 「開く」ボタンが表示される

### 2. 検索機能
- [ ] 検索ボックスが表示される
- [ ] 検索ボックスにプレースホルダー「ドキュメントを検索...」が表示される
- [ ] タイトルで検索できる
- [ ] 説明文で検索できる
- [ ] 検索結果がリアルタイムで更新される
- [ ] 検索結果が見つからない場合、適切なメッセージが表示される

### 3. カテゴリフィルター機能
- [ ] カテゴリ選択ドロップダウンが表示される
- [ ] 「すべてのカテゴリ」オプションが選択されている
- [ ] 各カテゴリでフィルタリングできる
- [ ] カテゴリタブが表示される
- [ ] タブ切り替えでカテゴリ別表示ができる

### 4. ドキュメント表示機能
- [ ] ドキュメントカードをクリックしてドキュメントを開ける
- [ ] ドキュメントの内容がMarkdownとして正しく表示される
- [ ] 見出し（h1, h2, h3）が適切にスタイリングされる
- [ ] リスト（ul, ol）が適切に表示される
- [ ] コードブロックが適切に表示される
- [ ] テーブルが適切に表示される
- [ ] リンクが適切に表示される

### 5. ナビゲーション機能
- [ ] ドキュメント表示時に「一覧に戻る」ボタンが表示される
- [ ] 「一覧に戻る」ボタンでドキュメント一覧に戻れる
- [ ] ブラウザの戻るボタンで正常にナビゲーションできる

### 6. 管理者機能（管理者ユーザーの場合）
- [ ] 管理者の場合、承認ボタンが表示される
- [ ] 承認ダイアログが表示される
- [ ] 承認チェックリストが表示される
- [ ] すべての項目にチェックを入れると承認ボタンが有効になる
- [ ] 承認が完了すると「承認済」状態になる

### 7. レスポンシブデザイン
- [ ] デスクトップ表示で正常に表示される
- [ ] タブレット表示で正常に表示される
- [ ] モバイル表示で正常に表示される
- [ ] カードレイアウトが適切に調整される
- [ ] 検索ボックスとフィルターが適切に配置される

### 8. ローディング状態
- [ ] ドキュメント一覧読み込み時にローディング表示される
- [ ] 個別ドキュメント読み込み時にローディング表示される
- [ ] ローディング中は適切なスピナーが表示される

### 9. エラーハンドリング
- [ ] ドキュメントが見つからない場合、エラーメッセージが表示される
- [ ] ネットワークエラー時に適切なメッセージが表示される
- [ ] エラー発生時に「一覧に戻る」ボタンが表示される

### 10. パフォーマンス
- [ ] ドキュメント一覧の読み込み時間が3秒以内である
- [ ] 個別ドキュメントの読み込み時間が2秒以内である
- [ ] 検索結果の表示が1秒以内である
- [ ] ページの初期読み込み時間が5秒以内である

### 11. アクセシビリティ
- [ ] キーボード操作でナビゲーションできる
- [ ] スクリーンリーダーで内容が読み上げられる
- [ ] 適切なラベルが設定されている
- [ ] フォーカス表示が適切である
- [ ] コントラスト比が適切である

### 12. API連携
- [ ] `/api/docs?action=list`でドキュメント一覧を取得できる
- [ ] `/api/docs?action=categories`でカテゴリ一覧を取得できる
- [ ] `/api/docs?action=content&id={docId}`でドキュメント内容を取得できる
- [ ] APIエラー時に適切なエラーハンドリングが行われる

## 判定基準（合否）
- 上記すべてのケースが期待結果どおりであること
- ドキュメントが正確に表示・検索されること
- 管理者機能が適切に動作すること
- ブラウザのコンソールに致命的エラーが出ていないこと
- レスポンシブデザインが適切に動作すること
- パフォーマンス要件を満たしていること

## 付記
- ドキュメントファイルは`public/docs/`ディレクトリに配置
- カテゴリは`features`, `api`, `user-guide`, `admin`, `development`をサポート
- Markdownのレンダリングには`react-markdown`を使用
- 数式表示には`remark-math`と`rehype-katex`を使用
- テーブル表示には`remark-gfm`を使用
