# 📄 ドキュメント機能 操作手順書

## 1. 概要

### 1.1 機能の目的
ドキュメント機能は、プロジェクトの各種ドキュメントを効率的に管理・表示するための機能です。Markdown形式のドキュメントを一覧表示し、検索・フィルタリング機能を提供します。

### 1.2 対象ユーザー
- **一般ユーザー**: ドキュメントの閲覧・検索
- **管理者**: ドキュメントの承認・管理

## 2. 基本操作

### 2.1 ドキュメント一覧の表示

#### 2.1.1 アクセス方法
1. ブラウザでアプリケーションにアクセス
2. サイドバーまたはメニューから「📄 ドキュメント」をクリック
3. ドキュメント一覧ページが表示される

#### 2.1.2 表示内容
- **ページタイトル**: 「ドキュメント」
- **検索ボックス**: ドキュメントを検索するための入力フィールド
- **カテゴリ選択**: ドキュメントをカテゴリ別にフィルタリング
- **ドキュメントカード**: 各ドキュメントの情報を表示

#### 2.1.3 ドキュメントカードの情報
- **タイトル**: ドキュメントのタイトル
- **カテゴリバッジ**: ドキュメントのカテゴリ
- **説明文**: ドキュメントの概要（最初の段落）
- **最終更新日**: ドキュメントの最終更新日時
- **ファイルサイズ**: ドキュメントのファイルサイズ
- **開くボタン**: ドキュメントを開くためのボタン

### 2.2 ドキュメントの検索

#### 2.2.1 検索方法
1. 検索ボックスに検索キーワードを入力
2. 入力と同時に検索結果が更新される
3. 検索結果がリアルタイムで表示される

#### 2.2.2 検索対象
- **タイトル**: ドキュメントのタイトル
- **説明文**: ドキュメントの説明文

#### 2.2.3 検索結果
- 検索条件に一致するドキュメントのみが表示される
- 検索結果が見つからない場合は「ドキュメントが見つかりません」メッセージが表示される

### 2.3 カテゴリ別フィルタリング

#### 2.3.1 カテゴリ選択方法
1. カテゴリ選択ドロップダウンをクリック
2. 表示されたカテゴリ一覧から選択
3. 選択したカテゴリのドキュメントのみが表示される

#### 2.3.2 利用可能なカテゴリ
- **すべて**: 全ドキュメントを表示
- **機能仕様書**: 各機能の要件定義、設計書、テスト仕様書
- **API仕様書**: APIエンドポイントの仕様とドキュメント
- **ユーザーガイド**: ユーザー向け操作手順書
- **管理者向けドキュメント**: 管理者向けの運用手順書
- **開発者向けドキュメント**: 開発者向けの技術仕様書

#### 2.3.3 タブ形式での切り替え
1. カテゴリタブをクリック
2. 選択したカテゴリのドキュメントが表示される
3. 各カテゴリタブには説明文も表示される

### 2.4 ドキュメントの表示

#### 2.4.1 ドキュメントを開く
1. ドキュメントカードの「開く」ボタンをクリック
2. ドキュメントの詳細ページが表示される
3. Markdown形式でレンダリングされた内容が表示される

#### 2.4.2 表示される内容
- **見出し**: h1, h2, h3の階層構造
- **段落**: テキストの段落
- **リスト**: 箇条書きリスト（ul, ol）
- **コードブロック**: コードの表示
- **テーブル**: 表形式のデータ
- **リンク**: 外部リンクや内部リンク
- **数式**: LaTeX記法の数式（対応する場合）

#### 2.4.3 ナビゲーション
- **一覧に戻る**: ドキュメント一覧に戻るボタン
- **ブラウザの戻るボタン**: 前のページに戻る

## 3. 管理者機能

### 3.1 ドキュメントの承認

#### 3.1.1 承認機能の表示
- 管理者権限を持つユーザーのみが表示される
- ドキュメント表示ページに「承認」ボタンが表示される

#### 3.1.2 承認手順
1. ドキュメント表示ページで「承認」ボタンをクリック
2. 承認ダイアログが表示される
3. 承認チェックリストの各項目にチェックを入れる
4. すべての項目にチェックを入れると「承認する」ボタンが有効になる
5. 「承認する」ボタンをクリックして承認を完了

#### 3.1.3 承認チェックリスト
承認するドキュメントの種類に応じて異なるチェックリストが表示されます：

**要件定義書の場合**:
- 目的とスコープが具体的で検証可能
- 機能要件が網羅され曖昧さがない
- 非機能要件（性能/可用性/セキュリティ/アクセシビリティ）が定義済み
- API入出力・データフロー・依存関係が明記されている
- 完了条件と受け入れ基準が明確
- リスクと対応が列挙されている

**基本設計書の場合**:
- 画面/コンポーネント構成と責務が適切に定義されている
- 入力項目・バリデーション・エラー表示の方針が定義済み
- API 呼び出しと例外/再試行の振る舞いが設計済み
- ローディング/成功/失敗時の UX が定義済み
- アクセス制御・権限・FeatureAccessGuard の考慮がある
- アクセシビリティ/セキュリティの基本方針が明記されている

**詳細設計書の場合**:
- API I/F（入出力スキーマ・エラーケース）が網羅されている
- トークン保存/更新処理のシーケンスが定義されている
- ルーティングと遷移条件（post_login_redirect など）が明確
- 状態管理とテスト観点（単体/結合/総合）が定義済み
- セキュリティ詳細（XSS/CSRF/トークン保護）が定義済み
- ログ/監査・計測項目が定義されている

#### 3.1.4 承認状態の表示
- 承認済みのドキュメントは「承認済」ボタンが表示される
- 承認状態は永続的に保存される

## 4. トラブルシューティング

### 4.1 よくある問題と解決方法

#### 4.1.1 ドキュメントが表示されない
**症状**: ドキュメント一覧が空または「ドキュメントが見つかりません」と表示される

**原因と解決方法**:
1. **ネットワーク接続の問題**
   - インターネット接続を確認
   - ページを再読み込み

2. **APIエラー**
   - ブラウザの開発者ツールでコンソールエラーを確認
   - 管理者に連絡

3. **ドキュメントファイルの問題**
   - ドキュメントファイルが正しく配置されているか確認
   - ファイルの権限を確認

#### 4.1.2 検索結果が表示されない
**症状**: 検索キーワードを入力しても結果が表示されない

**原因と解決方法**:
1. **検索キーワードの問題**
   - キーワードのスペルを確認
   - より一般的なキーワードで検索

2. **カテゴリフィルターの問題**
   - 「すべて」カテゴリを選択
   - 他のカテゴリでも試す

#### 4.1.3 ドキュメントの内容が正しく表示されない
**症状**: Markdownの記法が正しくレンダリングされない

**原因と解決方法**:
1. **Markdown記法の問題**
   - ドキュメントのMarkdown記法を確認
   - 正しい記法に修正

2. **特殊文字の問題**
   - 特殊文字やエンコーディングを確認
   - UTF-8エンコーディングを使用

#### 4.1.4 承認機能が表示されない
**症状**: 管理者なのに承認ボタンが表示されない

**原因と解決方法**:
1. **権限の問題**
   - 管理者権限が正しく付与されているか確認
   - ログアウト・ログインを試す

2. **ドキュメントタイプの問題**
   - 承認対象のドキュメントタイプか確認
   - 要件定義書、設計書、テスト仕様書などが対象

### 4.2 エラーメッセージの対処

#### 4.2.1 「ドキュメントの読み込みに失敗しました」
- ネットワーク接続を確認
- ページを再読み込み
- しばらく時間をおいて再試行

#### 4.2.2 「ドキュメントが見つかりませんでした」
- ドキュメントが存在するか確認
- 正しいURLでアクセスしているか確認
- ドキュメント一覧から再度アクセス

#### 4.2.3 「サーバーエラーが発生しました」
- 管理者に連絡
- しばらく時間をおいて再試行
- ブラウザのキャッシュをクリア

## 5. パフォーマンス最適化

### 5.1 読み込み時間の改善
- **キャッシュの活用**: ブラウザのキャッシュを有効にする
- **ネットワーク環境**: 安定したネットワーク環境で利用
- **同時アクセス**: 同時アクセス数を制限する

### 5.2 検索の最適化
- **キーワードの選択**: 具体的で適切なキーワードを使用
- **カテゴリの活用**: カテゴリフィルターを併用
- **結果の絞り込み**: 検索結果を段階的に絞り込む

## 6. セキュリティ注意事項

### 6.1 アクセス制御
- 管理者権限は適切に管理する
- 不要な権限は付与しない
- 定期的に権限の見直しを行う

### 6.2 ドキュメントの管理
- 機密情報を含むドキュメントは適切に管理する
- 不要なドキュメントは削除する
- 定期的にドキュメントの内容を確認する
