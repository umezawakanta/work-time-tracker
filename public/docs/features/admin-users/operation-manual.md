# 管理ユーザー機能 運用マニュアル

## 概要
管理者がユーザー一覧を表示し、ユーザーの情報を更新・削除できる機能の運用に関する情報をまとめています。

## 機能概要
- **機能名**: 管理ユーザー
- **機能ID**: `admin-users`
- **パス**: `/admin/users`
- **カテゴリ**: 運用
- **ステータス**: 完成
- **優先度**: P0
- **リリース日**: 2025-09-06

## 機能詳細
### ユーザー一覧表示
- 全ユーザーの一覧表示
- ページネーション（20件/ページ）
- 検索機能（メールアドレス、ユーザー名）
- ソート機能（作成日時、メールアドレス、名前）

### ユーザー情報表示
- ユーザーID
- 名前
- メールアドレス
- ロール（user/admin）
- アクティブ状態
- ブロック状態
- 作成日時
- 最終ログイン日時

### ユーザー操作
- ロール変更（user ↔ admin）
- アクティブ状態変更（有効 ↔ 無効）
- ブロック状態変更（ブロック ↔ アンブロック）
- ユーザー削除
- サブスクリプション管理

## アクセス制御
### 権限要件
- 管理者権限（`role: 'admin'`）が必要
- 認証済みユーザーのみアクセス可能

### 権限チェック
```javascript
// 管理者権限チェック例
if (user?.role !== 'admin') {
  // アクセス拒否
  return res.status(403).json({ error: 'Forbidden' });
}
```

## 技術仕様
### フロントエンド
- **ページ**: `src/pages/AdminUsersPage.tsx`
- **API**: `src/services/api/adminUsersApi.ts`
- **コンポーネント**: `src/components/admin/AdminUserSubscriptionPanel.tsx`

### バックエンド
- **一覧取得**: `api/admin/users/index.ts`
- **個別操作**: `api/admin/users/[id].ts`
- **データベース**: MongoDB

### API エンドポイント
- `GET /api/admin/users` - ユーザー一覧取得
- `PATCH /api/admin/users/[id]` - ユーザー情報更新
- `DELETE /api/admin/users/[id]` - ユーザー削除

## トラブルシューティング
### よくある問題

#### 1. ユーザー一覧が表示されない
**症状**: ユーザー一覧が空またはエラーが表示される

**原因**:
- データベース接続エラー
- 権限不足
- API エンドポイントのエラー

**対処法**:
1. データベース接続を確認
2. 管理者権限を確認
3. API エンドポイントのログを確認

#### 2. ユーザー情報の更新が失敗する
**症状**: ユーザー情報の更新が反映されない

**原因**:
- データベース更新エラー
- バリデーションエラー
- 権限不足

**対処法**:
1. データベースの状態を確認
2. 入力値のバリデーションを確認
3. 権限設定を確認

#### 3. 検索機能が動作しない
**症状**: 検索キーワードを入力しても結果が表示されない

**原因**:
- 検索クエリのエラー
- インデックスの問題
- フロントエンドのバグ

**対処法**:
1. 検索クエリのログを確認
2. データベースのインデックスを確認
3. フロントエンドのデバッグを実行

#### 4. 権限エラーが発生する
**症状**: 管理者権限があるのにアクセスが拒否される

**原因**:
- セッションの期限切れ
- 権限チェックのバグ
- データベースの権限情報の不整合

**対処法**:
1. セッションの状態を確認
2. 権限チェックロジックを確認
3. データベースの権限情報を確認
