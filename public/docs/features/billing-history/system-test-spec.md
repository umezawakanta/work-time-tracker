# 請求履歴機能 総合試験仕様書

## 機能概要
過去の請求書と支払い履歴を表示する機能

## 試験環境
- 本番環境: https://work-time-tracker-five.vercel.app
- テスト環境: http://localhost:3000

## 前提条件
1. 有効なユーザーアカウントでログイン済み
2. サブスクリプションプランに加入済み（有料プラン）
3. Stripe APIキーが正しく設定されている

## 試験項目

### 1. 基本表示機能
- [ ] 請求履歴ページにアクセスできる
- [ ] ログインしていない場合はログインページにリダイレクトされる
- [ ] ページタイトル「請求と支払い」が表示される
- [ ] タブ「請求履歴」「支払い方法」が表示される

### 2. 請求履歴表示
- [ ] 過去の請求書一覧が表示される
- [ ] 各請求書に以下の情報が表示される
  - [ ] 請求日
  - [ ] プラン名（プレミアムプラン等）
  - [ ] 請求期間（開始日-終了日）
  - [ ] 金額（日本円表示）
  - [ ] ステータス（支払い済み/未払い/失敗）
  - [ ] 請求書ダウンロードボタン
- [ ] 請求履歴がない場合は「請求履歴はありません」が表示される

### 3. 支払い方法表示
- [ ] 現在の支払い方法が表示される
- [ ] クレジットカードの場合、カード番号の下4桁が表示される
- [ ] 支払い方法が登録されていない場合は「登録されていません」が表示される

### 4. 次回請求情報
- [ ] 有料プランの場合、次回請求日が表示される
- [ ] 自動更新が停止されている場合は警告メッセージが表示される
- [ ] フリープランの場合は次回請求情報が表示されない

### 5. 請求書エクスポート
- [ ] 「すべての請求書をダウンロード」セクションが表示される
- [ ] CSVダウンロードボタンが表示される

### 6. エラーハンドリング
- [ ] APIエラー時に適切なエラーメッセージが表示される
- [ ] ネットワークエラー時に適切なエラーメッセージが表示される
- [ ] ローディング中はスピナーが表示される

### 7. レスポンシブデザイン
- [ ] モバイルデバイスで適切に表示される
- [ ] タブレットデバイスで適切に表示される
- [ ] デスクトップで適切に表示される

### 8. アクセシビリティ
- [ ] キーボードナビゲーションが可能
- [ ] スクリーンリーダーで適切に読み上げられる
- [ ] 適切なARIAラベルが設定されている

## 試験データ
- テスト用のStripe顧客ID: 使用するテストアカウントの顧客ID
- テスト用の請求書: Stripeテスト環境で作成した請求書

## 期待結果
- すべての試験項目が合格する
- 本番環境でStripe APIと正常に連携する
- モックやダミー処理が含まれていない
- エラーが発生しない

## 備考
- 請求履歴はStripe APIから取得される
- 支払い方法情報はStripe APIから取得される
- 請求書のダウンロード機能は将来実装予定
