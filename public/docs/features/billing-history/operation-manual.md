# 請求履歴機能 運用マニュアル

## 機能概要
過去の請求書と支払い履歴を表示する機能。Stripe APIと連携して実際の請求データを取得・表示します。

## 技術仕様

### フロントエンド
- **ページ**: `/billing-history`
- **コンポーネント**: `BillingHistoryPage.tsx`
- **API**: `userSubscriptionApi.getInvoiceHistory()`

### バックエンド
- **エンドポイント**: `/api/userSubscription/invoices/[userId]`
- **認証**: JWT認証必須
- **外部API**: Stripe API連携

### データフロー
1. ユーザーが請求履歴ページにアクセス
2. JWT認証でユーザーIDを取得
3. Stripe顧客IDを取得
4. Stripe APIから請求履歴を取得
5. レスポンス形式に変換してフロントエンドに返却

## 運用手順

### 1. 監視項目
- **API応答時間**: 3秒以内
- **エラー率**: 5%以下
- **Stripe API制限**: 月間100回以内

### 2. エラー対応
- **認証エラー**: ログイン画面にリダイレクト

### 4. メンテナンス

## トラブルシューティング

### よくある問題

#### 1. 請求履歴が表示されない
**原因**: Stripe顧客IDが未設定
**対処**: ユーザーのStripe顧客IDを確認・設定

#### 2. 支払い方法が表示されない
**原因**: 支払い方法が未登録
**対処**: ユーザーに支払い方法の登録を案内

#### 3. APIエラーが発生する
**原因**: Stripe APIキーの設定ミス
**対処**: 環境変数の確認・修正

### 緊急時対応
1. **サービス停止**: 機能を一時的に無効化
2. **データ不整合**: キャッシュクリア
3. **API制限超過**: レート制限の確認
