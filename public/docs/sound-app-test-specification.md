# 音アプリ 総合試験仕様書

## 概要

この文書は、音アプリの全機能が正常に動作することを確認するための総合試験仕様書です。Phase 1〜4で実装されたすべての機能について、詳細なテストケースを定義しています。

## テスト環境

- **ブラウザ**: Chrome 120+, Firefox 120+, Safari 17+, Edge 120+
- **OS**: Windows 10+, macOS 12+, Ubuntu 20.04+
- **デバイス**: デスクトップ、タブレット、スマートフォン
- **解像度**: 1920x1080, 1366x768, 768x1024, 375x667

## テストカテゴリ

### 1. 基本機能テスト

#### 1.1 食事記録機能
**テストケース 1.1.1: 数値入力での食事記録**
- **前提条件**: 音アプリが起動している
- **手順**:
  1. 各カテゴリ（主食、副菜、味噌、肉、魚、野菜）に数値を入力
  2. 入力値を確認
  3. リセットボタンをクリック
- **期待結果**: 
  - 入力値が正しく反映される
  - リセット後、すべての値が0になる
- **重要度**: 高

**テストケース 1.1.2: ドラッグ&ドロップでの食事記録**
- **前提条件**: ドラッグ&ドロップモードが有効
- **手順**:
  1. 食べ物アイコンをドラッグ
  2. ドロップゾーンにドロップ
  3. 成功アニメーションを確認
- **期待結果**:
  - ドラッグ&ドロップが正常に動作する
  - 記録数が1増加する
  - 成功アニメーションが表示される
- **重要度**: 高

#### 1.2 音楽生成機能
**テストケース 1.2.1: 基本音楽生成**
- **前提条件**: 食事記録が完了している
- **手順**:
  1. ジャンルを選択
  2. 楽器を選択
  3. 再生ボタンをクリック
- **期待結果**:
  - 音楽が正常に再生される
  - 楽譜が表示される
  - 音の可視化が表示される
- **重要度**: 高

**テストケース 1.2.2: ジャンル別音楽生成**
- **前提条件**: 同じ食事記録でテスト
- **手順**:
  1. 各ジャンル（バランス、明和電機、ロック、テクノ、クラシック、和楽器、ジャズ、アンビエント、カスタム）を順次選択
  2. 音楽を再生
- **期待結果**:
  - 各ジャンルで異なる音楽が生成される
  - テンポ、調、音色がジャンルに応じて変化する
- **重要度**: 高

#### 1.3 楽器選択機能
**テストケース 1.3.1: 楽器別音色**
- **前提条件**: 同じ音楽設定でテスト
- **手順**:
  1. 各楽器（ピアノ、ギター、ドラム、ベース、シンセ、明和電機風）を順次選択
  2. 音楽を再生
- **期待結果**:
  - 各楽器で異なる音色が生成される
  - 音の可視化が楽器に応じて変化する
- **重要度**: 高

### 2. 高度機能テスト

#### 2.1 栄養分析機能

#### 2.2 動的パターン生成
**テストケース 2.2.1: 食事内容に応じたパターン**

- **期待結果**:
