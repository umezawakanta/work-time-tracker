# フォント設定機能 設計書

## 概要

Work Time Trackerのフォント設定機能を改善し、こどもでも使いたくなるような可愛いフォントを追加し、日本語・英語の同時設定機能を強化する。

## 現状分析

### 既存機能
- 日本語・英語の個別フォント設定機能（`LanguageFontSettings`）
- フォントプレビュー機能
- ローカルストレージでの設定保存
- CSS変数による動的フォント適用

### 課題
1. こども向けフォントが不足
2. フォント設定の確認が困難
3. プレビュー機能が限定的
4. フォントの適用範囲が不明確

## 要件定義

### 機能要件

#### 1. こども向けフォントの追加
- **日本語フォント**
  - 丸文字系フォントの充実

  - 可愛いキャラクター風フォント

- **英語フォント**
  - 楽しいデザインフォント

  - 学習に適したフォント

- リアルタイムプレビュー

#### 3. フォント適用範囲の明確化
- 各フォントが適用される要素の表示

#### 4. ユーザビリティの向上
- フォントカテゴリの分類

## システム設計

### アーキテクチャ

```
FontSettingsSystem
├── FontManager (フォント管理)
│   ├── FontLoader (フォント読み込み)
│   ├── FontPreview (プレビュー表示)
│   └── FontApplier (フォント適用)
├── FontDatabase (フォントデータベース)
│   ├── JapaneseFonts (日本語フォント)
│   ├── EnglishFonts (英語フォント)
│   └── ChildFriendlyFonts (こども向けフォント)
└── FontUI (ユーザーインターフェース)
    ├── FontSelector (フォント選択)
    ├── FontPreview (プレビュー)
    └── FontSettings (設定管理)
```

### データ構造

#### FontOption 拡張
```typescript
interface FontOption {
  value: string;
  label: string;
  category: 'japanese' | 'english' | 'system' | 'child-friendly';
  subcategory: 'rounded' | 'handwriting' | 'cute' | 'school' | 'modern' | 'classic';
  ageGroup: 'all' | 'child' | 'teen' | 'adult';
  readability: 'high' | 'medium' | 'low';
  description: string;
  previewText: string;
  tags: string[];
}
```

#### FontSettings 拡張
```typescript
interface FontSettings {
  japanese: string;
  english: string;
  childMode: boolean;
  fontSize: 'small' | 'medium' | 'large';
  lineHeight: 'tight' | 'normal' | 'loose';
  favorites: string[];
}
```
