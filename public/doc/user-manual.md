# Work Time Tracker - 包括的個人管理システム ユーザーマニュアル

## 1. システム概要

**Work Time Tracker - 包括的個人管理システム**は、資産・負債管理、収入・支出追跡、行動記録、未来計画、データ分析を統合した個人向けライフマネジメントツールです。

### 1.1 システムの目的

「人生なんて簡単だ。すべての欲望をコントロールさえできれば。計画を立てて計画通り行動できれば。すべての行動を記録して見直しできれば。まずは自分の資産、負債、収入、支出、過去の行動、今後の予定を把握するところから始めよう。次にすることは自分から搾取しているものを把握して身を守ろう。」

このシステムは、上記の理念に基づいて設計されており、個人の完全な自己管理を支援します。

## 2. 主要機能

### 2.1 統合ダッシュボード 🏠

**目的**: すべての情報を一覧で把握し、鳥瞰的な視点で個人の状況を把握

**機能**:
- 資産・負債の総合表示
- 月次収支サマリー
- 今月の支出カテゴリ別内訳
- 最近の行動記録
- 今後の予定・計画
- 改善提案と予測

**アクセス方法**:
1. メイン画面で「🏠 統合ダッシュボード」ボタンをクリック
2. すべての情報が一つの画面に表示されます

### 2.2 資産・負債管理 💰

  - 残高の更新

- **口座間の振替記録**

  - カード名、残高、利用可能枠の記録

  - 返済予定日の管理
  - 金利の記録

- **PayPayカード残高**
  - PayPayカードの残高管理
  - 利用履歴の記録

#### 2.2.4 搾取要素の監視
- **サブスクリプション料金**
  - サービス名、月額料金、更新日の記録

  - 解約の管理

- **自動引き落とし**
  - 引き落とし先、金額、日付の記録

**支出の記録**
1. 「📊 データ分析」ボタンをクリック

   - サブカテゴリ（任意）
   - タグ（任意）

1. 「📝 行動記録」ボタンをクリック
2. 「+ 行動を記録」をクリック

   - サブカテゴリ（任意）
   - 開始時間
   - 終了時間（任意）
   - 場所（任意）
   - 参加者（任意）

   - 気分評価
   - エネルギー評価

## 4. トラブルシューティング

### 4.1 よくある問題

#### 4.1.1 データが保存されない
**原因**: ブラウザのローカルストレージの問題
**解決方法**:
1. ブラウザの設定を確認
2. ローカルストレージを有効化
3. ブラウザのキャッシュをクリア
4. ページを再読み込み

#### 4.1.2 計算が合わない
**原因**: 入力データの問題
**解決方法**:
1. 入力データを確認
2. 小数点の扱いを確認
3. 通貨の単位を確認
4. 計算式を確認

#### 4.1.3 表示が崩れる
**原因**: ブラウザの互換性の問題
**解決方法**:
1. ブラウザを最新版に更新
2. ブラウザのキャッシュをクリア
3. JavaScriptを有効化
4. 別のブラウザで試す

#### 4.1.4 ログインできない
**原因**: 認証情報の問題
**解決方法**:
1. メールアドレスとパスワードを確認
2. パスワードをリセット
3. アカウントの状態を確認
4. 管理者に問い合わせ

### 4.2 サポート

#### 4.2.1 ヘルプページの確認
1. アプリケーション内のヘルプを確認
2. よくある質問を確認
3. 使用方法を確認

#### 4.2.2 よくある質問の確認
1. FAQページを確認
2. 関連する質問を検索
3. 解決方法を確認

#### 4.2.3 管理者への問い合わせ
1. 問い合わせフォームを使用
2. 問題の詳細を記録
3. スクリーンショットを添付
4. 返信を待つ
